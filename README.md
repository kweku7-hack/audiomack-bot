# 🎵 Audiomack Telegram Downloader Bot

A Telegram bot that downloads MP3 files from Audiomack links. Just send any song URL and receive the audio instantly!

## ✨ Features
- Download any public Audiomack song
- High quality MP3 format
- Fast response time
- 24/7 online (hosted on Render)
- No registration required

## 🚀 Quick Deploy
Deploy to Render in 5 minutes - free tier available!

## 📱 Commands
- `/start` - Start the bot
- `/help` - Show help message
- Just send any Audiomack URL to download
